About

Backend and full-stack, owned end to end

I'm a senior software engineer based in Lahore, Pakistan. Over the past four years I've built and shipped backend services, full-stack web platforms and mobile products for companies including Blue Horn Technologies, SolutionWin Technologies, Technotz and Teraception. I like owning a feature all the way through — schema design, the API contract, the client application, and the deployment.

On the infrastructure side I run the production stack for my own SaaS myself: a multi-stage Dockerfile behind Nginx and Supervisor, a Docker Compose stack with MySQL and Redis on a private bridge network, TLS terminated at the proxy, and every credential externalised to environment variables. I've also moved live applications between hosting environments — shared hosting to VPS to AWS, including DNS cutover, SSL certificates and transactional email — and that work is the part most teams underestimate.

Lately I've been building AI-backed features into production systems: retrieval-augmented generation pipelines and Model Context Protocol (MCP) integrations, wired into real application workflows rather than demo scripts.
